# Barbershop & Tattoo

Полноценный сайт барбершопа с онлайн-записью, личными кабинетами и системой подарочных сертификатов.

## Возможности
- Онлайн-запись с выбором мастера, даты и времени
- Оплата подарочными сертификатами
- Личные кабинеты для клиентов и мастеров
- Админ-панель для управления записями, услугами и персоналом
- Система восстановления пароля через email

## Технологии
- PHP (ООП)
- MySQL
- Vanilla JavaScript
- CSS3 (Grid, Flexbox, CSS Variables)
- PHPMailer

## Установка
1. Склонируйте репозиторий
2. Импортируйте базу данных 
3. Настройте `config/db.php` и `config/mail.php`
4. Запустите через локальный сервер (OpenServer/XAMPP)
